# 招投标智能技能系统

一个面向企业招投标工作的多 Skill 协作系统，帮助企业从招标文件分析、资格与评分点提取，到投标方案编制、资料管理和最终审查，形成一套可追溯、可复核、低幻觉的投标辅助流程。

本项目以四川省科智汇川人工智能科技有限责任公司作为投标主体，使用真实政府采购磋商资料完成了验证。

## 项目解决的问题

传统投标工作容易出现以下问题：

- 招标要求、废标项和评分点混在一起
- 技术参数、证明材料和响应文件无法对应
- 企业资料版本混乱，证据有效期难以追踪
- 方案内容容易遗漏评分点
- 人员、业绩、资质和产品能力被误写或编造
- 最终文件存在金额、日期、公司名称和附件不一致

本项目将投标工作拆分为四个专业角色，并由一个总控 Skill 统一调度。

## 核心架构

```text
招投标项目总控
        |
        +-- 投标助理：读规则、拆任务、提取废标项和评分点
        |
        +-- 文档秘书：管资料、管版本、维护证据索引和格式
        |
        +-- 售前助手：搭提纲、写初稿、形成实施与服务方案
        |
        +-- 文档审查员：查遗漏、查冲突、核对附件与签章
        |
        +-- 企业档案：管理企业资质、人员、业绩和产品证据
```

工作流：

```text
ANALYZE -> GATHER -> DRAFT -> REVIEW -> REMEDIATE -> FINALIZE -> HANDOFF
```

## Skill 组成

| Skill | 主要职责 |
| --- | --- |
| `bid-orchestrator` | 总控项目状态、调度角色、路由问题回流 |
| `tender-analyst` | 分析招标规则、提取资格条件、废标项和评分点 |
| `doc-secretary` | 管理资料目录、版本、证据索引、格式规范和缺口 |
| `presales-writer` | 生成投标提纲、技术方案、实施方案、售后方案和服务应答表初稿 |
| `compliance-reviewer` | 检查遗漏、冲突、附件、签章和最终提交条件 |
| `company-profile` | 管理企业主体资料和证据状态 |

## 防幻觉设计

### 1. 五级内容标记

所有方案正文必须使用以下标记：

- `[已确认]`：有招标原文或企业资料直接支撑
- `[合理拟定]`：依据需求设计的方案建议，不代表企业既成事实
- `[待补充]`：缺少企业资料，需要明确补充
- `[待确认]`：需要企业负责人决策或授权
- `[禁止直接使用]`：无证据支撑的业绩、资质、案例或承诺

### 2. 证据绑定

企业事实必须绑定证据编号，例如 `EV-001`。没有企业证据时，不得自动生成：

- 人员姓名和职称
- 项目业绩和合同
- 软件著作权和资质
- 产品数量和平台能力
- 案例、奖项和承诺

### 3. 废标项与评分项分离

系统将“未响应可能导致无效响应”的内容与“未满足会扣分”的内容分别维护，避免把普通评分项误判为废标项。

### 4. 确定性校验

校验脚本会检查：

- 方案正文是否缺少内容标记
- 废标项清单是否混入评分项
- 采购需求符号数量是否与评分细则一致

## 快速开始

### 安装到 Codex

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\skills\install.ps1
```

安装后，Skill 位于：

```text
C:\Users\<用户名>\.codex\skills\
```

### 使用方式

直接在 Codex 或支持 Agent Skills 的环境中使用自然语言：

```text
开始投标项目，读取当前资料包，先提取废标项和评分点。
```

```text
整理企业资料，建立证据索引和资料缺口清单。
```

```text
根据要求矩阵和评分点生成实施方案、售后服务方案和服务应答表初稿。
```

```text
审查投标文件，检查遗漏、冲突、附件和签章。
```

### 运行校验

```powershell
python skills/scripts/test_validate_workbench.py
python skills/scripts/validate_workbench.py projects/N5100012026002044
```

当输出中的 `errors` 为空时，表示工作台通过确定性规则校验。

## 边界说明

本项目是投标辅助 Skill 系统，不替代企业完成最终法律判断和平台操作：

- 不自动编造企业事实
- 不替企业决定报价和承诺
- 不生成电子签章
- 不判断电子签章法律效力
- 不代替企业在政府采购平台提交文件
- 最终投标文件必须由企业人工复核、签章和提交

## 适用场景

- 政府采购竞争性磋商
- 公开招标和邀请招标
- 服务类项目投标
- 技术方案和实施方案编制
- 企业投标资料库建设
- 投标文件合规审查
