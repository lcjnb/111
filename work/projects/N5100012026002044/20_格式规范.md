# 格式规范

本项目格式以磋商文件第六章响应文件格式和附件模板为准；下列为当前工作台默认规范，最终排版需在企业资料补齐后执行。

| 项目 | 规范 |
| --- | --- |
| 正文 | 宋体小四；招标文件另有要求时从其要求 |
| 标题 | 一级黑体三号，二级黑体四号 |
| 编号 | 一、 / （一） / 1. / （1） |
| 表格 | 保留招标文件最小序号；每表有表号和表题 |
| 文件名 | 投标响应文件-铁道移动AI课程-v版本-日期 |
| 页眉 | 项目名称 + 四川省科智汇川人工智能科技有限责任公司 |
| 页脚 | 第X页 共Y页 |
| 目录 | 正文定稿后生成，目录标题和页码逐项复核 |
| 附件顺序 | 响应文件封面、投标响应函、声明函、证明材料、服务应答表、报价表 |
| 盖章 | 仅保留盖章位置和提示，不由技能生成或判定电子印章 |
