# 抽取规则

## 符号语义

| 符号 | 语义 | 后果 |
| --- | --- | --- |
| ★ | 实质性要求 | 不允许负偏离，未响应即无效响应 |
| ▲ | 技术评分项 | 每项不满足扣 1.5 分 |
| ● | 技术评分项 | 每项不满足扣 0.5 分 |
| █ | 技术评分项 | 每项不满足扣 5 分 |
| 无符号 | 技术评分项 | 每项不满足扣 0.4 分 |

扣分值必须来自评分细则原文，不得套用其他项目的数值。

## 风险分级

| 等级 | 判定条件 |
| --- | --- |
| 阻断 | 未响应即无效响应；资格审查不通过；符合性审查不通过；★要求；超限价；未在截止时间提交 |
| 重大 | 评分项未覆盖；佐证材料缺失导致扣分；关键日期或金额不一致 |
| 一般 | 格式、措辞、编号、目录、页码问题 |

## 废标项判定条件

满足任一即为废标项：

1. 符合性审查标准表格中任一项
2. 标注 ★ 的要求
3. 响应有效期少于规定天数
4. 报价超过采购预算或最高限价
5. 未按要求提交中小企业声明函（专门面向中小企业采购的项目）
6. 联合体投标（项目不接受联合体时）
7. 未在规定时间内提交、解密、加盖电子印章

## 佐证要求抽取

技术要求中出现以下表述时，必须记录为佐证要求并写入要求矩阵的"响应方式"列：

| 表述 | 佐证类型 |
| --- | --- |
| 提供功能截图并加盖公章 | 截图 |
| 提供承诺函原件加盖公章 | 承诺函 |
| 提供案例佐证材料 | 案例 |
| 提供合同关键页复印件 | 合同 |
| 提供证书复印件 | 证书 |
| 提供备案证明 | 备案 |
| 现场演示 / 功能验证 | 现场演示 |
| 提供评审免密登陆主页备查 | 平台链接 |

## 常见错误

- 把评分项误判为废标项：评分项未满足只扣分，除非同时标注 ★
- 遗漏"以 PDF 为准"的优先级判定
- 只记录要求不记录来源，导致后续无法溯源
- 用其他项目的扣分分值套用
- 把佐证材料要求当作普通技术描述遗漏
