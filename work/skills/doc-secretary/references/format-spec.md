# 投标文件格式规范

具体数值以招标文件第六章响应文件格式要求为准；本文件仅在招标文件未明确规定时提供默认建议，使用前必须核对。

## 标题层级

| 层级 | 编号 | 用途 |
| --- | --- | --- |
| 一级 | 一、 | 章 |
| 二级 | （一） | 节 |
| 三级 | 1. | 条 |
| 四级 | （1） | 款 |

技术要求中的最小序号（1）（2）（3）必须原样保留，不得重新编号。

## 字体

| 元素 | 建议 |
| --- | --- |
| 正文 | 宋体 小四 |
| 一级标题 | 黑体 三号 |
| 二级标题 | 黑体 四号 |
| 表格文字 | 宋体 五号 |

## 页面

- 方向：纵向；表格过宽时可横向，但不得改变正文方向
- 页边距：上 3.5cm 下 2.5cm 左 2.8cm 右 2.6cm（招标文件另有规定时以其规定为准）
- 页眉：项目名称 + 供应商名称
- 页脚：第 X 页 共 Y 页

## 表格

- 每个表格必须有表号与表题，格式"表 X-X 表题"
- 表格必须有编号，编号连续不跳号
- 表格内的最小序号列必须与招标原文一致

## 文件命名

```
<分册名>-<项目简称>-v{n}-<日期>.<ext>
例：投标响应文件-铁道移动AI课程-v1-20261010.docx
```

## 附件顺序

附件按招标文件第六章"响应文件格式"的列举顺序排列，不自创顺序。

## 目录

- 目录在正文定稿后统一生成
- 目录条目必须与正文标题一致
- 目录页码与正文页码必须核对
- 目录变更后必须重新生成并复核

## 盖章位置

- 每个招标文件要求盖章的位置必须有明确的盖章标记
- 承诺函、声明函类文件在"供应商（盖章）"处标注
- 只做标记，不实际盖章
