```

  01_要求矩阵.md
  02_废标项清单.md
  03_评分点清单.md
  04_任务清单.md
  10_证据索引.md
  11_资料缺口清单.md
  12_版本记录.md
  20_格式规范.md
  30_投标文件提纲.md
  31_方案初稿/

  40_问题清单.md
  41_附件与签章检查表.md

```

编号分段即角色边界：

| 段位 | 归属角色 | 职责 |
| --- | --- | --- |
| 0x | 投标助理 | 规则解析与任务拆解 |
| 1x | 文档秘书 | 资料、证据、版本 |
| 2x | 文档秘书 | 格式规范 |
| 3x | 售前助手 | 提纲与方案初稿 |
| 4x | 文档审查员 | 问题、附件、提交检查 |

## 条目字段格式

要求矩阵、废标项、评分点统一使用以下字段，缺字段即不合格：

| 字段 | 说明 |
| --- | --- |
| 编号 | 项目内唯一，如 REQ-001 |
| 类别 | 资格 / 符合性 / 技术 / 商务 / 评分 |
| 符号 | ★ / ▲ / ● / █ / 无 |
| 风险等级 | 阻断 / 重大 / 一般 |
| 原文引用 | 招标原文摘录，不得改写 |
| 来源 | 文件名 + 章节号 + 页码 |
| 响应方式 | 承诺 / 证明材料 / 方案说明 / 偏离 |
| 证据编号 | 对应 10_证据索引.md 的证据号 |
| 状态 | 未开始 / 进行中 / 已完成 / 待人工 |

## 状态流转

```
ANALYZE -> GATHER -> DRAFT -> REVIEW -> REMEDIATE -> FINALIZE -> HANDOFF
```

每个状态的进入条件是该阶段的输出文件已存在且通过校验。
